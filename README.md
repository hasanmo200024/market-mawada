# ماركت المودة – نظام إدارة البضائع

**تصميم المودة للبرمجيات**

تطبيق ويب خفيف (ملف واحد `index.html` بدون تثبيت أو مكتبات خارجية) لإدارة محل أو شركة بضائع.

## المميزات
- إنشاء حساب وتسجيل دخول (الاسم، الهاتف، اسم الشركة، العنوان، كلمة المرور)
- المشتريات مرتبطة بالموردين، مع تقسيم سعر الكرتونة تلقائياً على عدد القطع
- أسعار بيع: قطاعي / جملة / جملة الجملة
- المبيعات على حساب العملاء أو نقدي، مع المدفوع والمتبقي
- كشف حساب للعملاء والموردين وتسجيل السداد
- كل العمليات بالتاريخ والوقت
- فواتير بالشعار قابلة للطباعة أو الحفظ PDF، مع تعديل وحذف الفواتير
- المخزن مع تنبيه نقص المخزون، والخزينة
- تقارير الأرباح بفلتر التاريخ
- تصدير CSV (Excel) ونسخ احتياطي واسترجاع

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو انشره على GitHub Pages:

1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد.
2. من **Settings → Pages** اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقائق يظهر الرابط: `https://USERNAME.github.io/REPO/`

## ملاحظات مهمة
- البيانات تُحفظ في متصفح الجهاز (localStorage) ولا تُرسل لأي خادم، فاعمل نسخة احتياطية دورياً من تبويب «نسخ احتياطي وتصدير».
- كلمة المرور تحمي الواجهة فقط وليست تشفيراً حقيقياً، فلا تعتمد عليها لحماية بيانات حساسة.
- لا تضع بيانات حقيقية للعملاء داخل المستودع نفسه.
